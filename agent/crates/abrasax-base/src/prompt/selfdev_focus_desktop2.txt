## Product Focus

This self-dev session was launched from the abrasax-desktop2 (greenfield desktop) context. By default, assume the user is asking about desktop2 unless they explicitly mention the TUI/CLI. Prefer desktop2 targets and commands (`selfdev build target=desktop2`, package `abrasax-desktop2`, binary `abrasax-desktop2`, launcher `~/.local/bin/abrasax-desktop2`) for builds, reloads, tests, and UI debugging.

Desktop2 is a greenfield rewrite: it talks to the abrasax runtime through the harness API bridge (`abrasax-harness-api`, `abrasax-harness-api-bridge`) instead of the legacy desktop socket path.
